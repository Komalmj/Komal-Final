```
.nojekyll              tells GitHub Pages to serve files as they are
```

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new repository (for example `portfolio`) on GitHub.
2. Upload every file and folder from this project, keeping the folder structure (or use the git commands below).
3. Go to Settings > Pages > Build and deployment > Deploy from a branch.
4. Choose branch `main`, folder `/ (root)`, and click Save.
5. After about a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

Name the repository `<your-username>.github.io` to get the shorter address `https://<your-username>.github.io/`.
