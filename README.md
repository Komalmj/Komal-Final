# Komal Minj - Portfolio

Graphic Designer & Video Editor portfolio. Plain HTML, CSS and JavaScript (no build step).

```
index.html        page structure and content
css/style.css     all styles
js/main.js        animations (scroll reveal, tools marquee, blinking cartoon)
assets/portrait.webp   cartoon portrait
```

Edit text in `index.html` (about, education) and in `js/main.js` (services, projects).

## Put it live with GitHub Pages
1. Upload all files and folders to a new repository (keep the folder structure).
2. Settings > Pages > Deploy from a branch > `main` / `/ (root)` > Save.
3. Live in about a minute at `https://<your-username>.github.io/<repo-name>/`.
